## Other FFXIV stuff

I'm also part of the **[DelvUI](https://github.com/DelvUI/DelvUI)** team. Most of my work there these days is through [pull requests](https://github.com/DelvUI/DelvUI/pulls?q=is%3Apr+author%3AZeffuro).

- **[FFXIV IDA Runner](https://github.com/Zeffuro/FFXIVIDARunner)**: Runs the usual post-patch IDA setup without babysitting every dialog.
- **[Zeffuro.PluginTemplate](https://github.com/Zeffuro/Zeffuro.PluginTemplate)**: An opinionated `dotnet new` template for starting Dalamud plugins. Still very much a work in progress.
- **[ZeffUI](https://github.com/Zeffuro/ZeffUI)**: An ACT/OverlayPlugin UI for FFXIV. It still works, but it is mostly in maintenance mode.
- **[UI Collections](https://github.com/Zeffuro/UI_Collections_FFXIV)**: DelvUI and DelvCD snippets, TPie rings, and presets for my own DelvUI profiles.
- **[Simple Triggernometry Trigger Creator](https://github.com/Zeffuro/SimpleTriggernometryTriggerCreator)**: I should probably rename this. It started as a Triggernometry trigger creator, but these days it is closer to an XIVAPI search tool.

## Other projects

- **[fakegaming-bot](https://github.com/Zeffuro/fakegaming-bot)**: My personal Discord bot. It grew into a larger project with separate bot, API, and dashboard Docker containers.
- **[zeff-boy](https://github.com/Zeffuro/zeff-boy)**: A multi-system emulator written in Rust. I started it to learn more about low-level programming and emulation.
- **[The X-Files PC Enhancement Patch](https://github.com/Zeffuro/x-files-pc-enhancement-patch)**: Unofficial PC enhancement patch for The X-Files Game, with QuickTime replacement, windowed and borderless display, controller improvements, and compatibility fixes for modern Windows.
